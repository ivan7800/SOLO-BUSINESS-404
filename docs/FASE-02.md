# Fase 02 · Gestión de clientes

- Edición de clientes sin alterar sus identificadores.
- Archivo y reactivación sin romper relaciones.
- Eliminación bloqueada si existen presupuestos, trabajos o documentos relacionados.
- Etiquetas, notas y hasta 20 contactos secundarios.
- NIF/NIE/CIF opcional con control local de dígito, sin consulta a AEAT.
- Búsqueda textual de clientes, etiquetas y contactos.
- Importación compatible con snapshots v1; campos nuevos opcionales.

**Demo:** datos locales; no almacenar información personal real o sensible.
