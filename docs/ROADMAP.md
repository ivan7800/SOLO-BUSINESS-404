# Roadmap · SOLO BUSINESS 404

- [x] Fase 01 — Diseño visual premium; navegación; modelo de demo; prototipo local; responsive; controles básicos y tests iniciales.
- [ ] Fase 02 — Clientes: edición, etiquetas, contactos, filtros avanzados, deduplicación, normalización NIF/CIF y validación.
- [ ] Fase 03 — Presupuestos: líneas, versiones, plantillas, aceptación firmada y seguimiento comercial.
- [ ] Fase 04 — Trabajos: estados, tiempos, materiales, adjuntos y relación con presupuestos.
- [ ] Fase 05 — Documentos fiscales de **prueba**: numeración conforme a reglas parametrizadas, cálculos tipificados, PDF no fiscal y pruebas de precisión.
- [ ] Fase 06 — Backend seguro, identidades, roles, organizaciones, PostgreSQL, migraciones, API y backup/restore.
- [ ] Fase 07 — Revisión jurídica/fiscal actualizada, integraciones oficiales pertinentes, registros técnicos y declaración responsable cuando proceda; sin habilitar emisión real hasta superar validaciones.
- [ ] Fase 08 — Indicadores reales, informes/exportaciones y automatizaciones autorizadas.
- [ ] Fase 09 — QA E2E, seguridad, concurrencia, rendimiento, accesibilidad, protección de datos y restauración.
- [ ] Fase 10 — Beta privada, soporte, términos legales, pricing y lanzamiento gradual.

**Regla de progresión:** cada fase se entrega con código y pruebas verificables. Las visualizaciones, importes y documentos fiscales simulados nunca deben presentarse como emisión legal.
