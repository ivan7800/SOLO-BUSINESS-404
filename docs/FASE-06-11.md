# Fase 6.11 — Infraestructura reproducible y controles de aislamiento

Esta entrega NO sustituye la fuente de verdad del frontend. Conserva la v0.6.10 y agrega infraestructura de pruebas reproducibles.

## Ejecutar en Windows

1. Instalar y arrancar Docker Desktop y Node.js 22.
2. Abrir PowerShell en `backend`.
3. Ejecutar `./run-e2e.ps1`.
4. Las migraciones se aplican **solo al crear un volumen nuevo**. Si el volumen ya existía, revisar esquema antes de repetir pruebas.
5. Para eliminar la base de pruebas: `docker compose down -v` (BORRA TODO EL VOLUMEN DE PRUEBAS).

## Linux / macOS

`cd backend && ./run-e2e.sh`

## CI

`.github/workflows/ci.yml` ejecuta tests frontend, tests backend y E2E PostgreSQL con un servicio efímero, al subir a GitHub. La existencia del workflow no demuestra que se haya ejecutado.

## Límites

- Se requiere PostgreSQL real para aprobar las pruebas E2E. En el entorno de preparación no está Docker ni PostgreSQL instalado.
- Frontend todavía guarda en localStorage. La escritura de entidades remotas continúa experimental: NO es PostgreSQL-first.
- Aún pendiente: recuperación real de backup, HTTPS, permisos por rol detallados, aislamiento completo y tests visuales de navegador.
- NO usar con datos personales o facturas reales.
